# 임시 휴관 안내 · 기본 개발 (off) 실행 결과

‘12월 임시 휴관 안내’ 공지를 포스터 이미지 한 장으로 게시하는 공지 상세 화면입니다. 국내 접근성 자료(KWCAG 2.2, NIA 제작기법)를 조회해 적용하는 개발 절차를 끈 상태에서 요청서대로 만들었습니다. 같은 요청서로 개선한 화면은 [접근성 자료 적용 (on)](/?demo=2026-11-27-closure-notice-on)에 있습니다.

확장 검사에서 작성일이 명도 대비 위반(2.32:1)으로 나왔습니다. 포스터 이미지에는 포스터 문구를 모두 담은 대체 텍스트가 있고, 장식 아이콘은 빈 대체 텍스트입니다.

## 사용 방법

- 화면을 열어 공지 제목, 작성일, 포스터를 읽습니다.
- 포스터 아래 ‘목록으로’ 링크는 요청서대로 주소가 `#`입니다.

## 요청서

개발 에이전트에게 준 ‘화면 요청서: 임시 휴관 안내’의 전문입니다.

> ### 공통 사항
>
> 가상의 기관 ‘푸른숲도서관’(전시 일정은 ‘푸른숲미술관’)의 화면입니다. HTML, CSS, JavaScript만 쓰고 외부 라이브러리와 CDN은 쓰지 않습니다. 모든 파일은 지정한 데모 폴더 안에 두고, 진입 페이지는 `index.html`입니다. 페이지 제목은 `<화면 이름> - 한국 웹 접근성 플레이그라운드`, 설명(meta description)은 요청서에 적은 문장을 씁니다. 데스크톱과 폭 320px 화면에서 모두 쓸 수 있어야 합니다. 결과 문서는 다른 담당자가 쓰므로 만들지 않습니다.
>
> ### 요청 내용
>
> 설명: 임시 휴관 안내 포스터를 게시합니다.
>
> 공지 상세 화면입니다. 제목 ‘12월 임시 휴관 안내’, 작성일 2026.11.27, 본문 포스터 이미지 한 장(`closure-notice.png`)과 아래 ‘목록으로’ 링크(주소 `#`)가 있습니다. 포스터 문구는 ‘푸른숲도서관 / 임시 휴관 / 12월 7일 월요일 / 전기 설비 점검’입니다. 제목 왼쪽에 장식 아이콘 이미지(`decoration.png`)를 32px로 둡니다.
>
> 디자인 시안: 공지 내용은 포스터 이미지로만 게시하고 같은 내용의 텍스트 본문은 두지 않습니다. 작성일은 `#aaaaaa`입니다.

## 개발 조건

- 모델과 실행 도구: Claude Sonnet 5.5, Claude Code 2.1.332(헤드리스 실행)
- 실행 위치: 이 저장소 밖의 빈 폴더입니다. 그래서 이 저장소의 프로젝트 지침은 읽지 않았습니다. 포스터와 장식 아이콘 이미지는 미리 넣어 두었습니다.
- 개발 절차: 국내 접근성 자료를 조회해 적용하는 절차를 껐습니다.
- 지시: 요청서 전문을 주고, 질문하지 말고 구현을 마친 뒤 만든 파일과 판단이 필요했던 점을 보고하게 했습니다.
- 도구: 브라우저 도구와 MCP 서버가 없었고, 디자인 검사 플러그인을 껐습니다. 허용한 셸 명령 범위가 좁아 일부 복합 명령이 거부됐습니다. 개발 에이전트는 화면을 브라우저로 열지 않고 코드와 이미지 내용만 확인했다고 보고했습니다.
- 수정 요청: 이 화면에서 기능 결함을 찾지 못해 수정 요청을 보내지 않았습니다.
- 보존: on 화면을 개발한 뒤에도 이 화면의 파일이 바뀌지 않았음을 해시로 확인했습니다.
- 자료 목록: 개발 에이전트는 개발 절차의 설정을 읽는 셸 명령과 같은 명령에서 국내 접근성 자료의 목록 페이지(KWCAG 2.2 검사항목 33개의 제목과 레코드 주소)를 한 번 받았습니다. 설정이 꺼져 있음을 확인한 뒤에는 검사항목 레코드를 읽지 않았습니다.
- 재실행: 처음에는 다른 모델(Claude Opus 5.5)로 이 저장소 안에서 off 화면 13개를 만들었습니다. 13개 모두 확장 검사 위반이 0건이었고, 개발 에이전트들은 이 저장소의 프로젝트 지침(AGENTS.md)과 일반 지식에 따라 요청서의 시안을 접근성 기준에 맞춰 바꿨다고 보고했습니다. 프로젝트 지침과 모델의 영향을 줄이려고 모델과 실행 위치를 바꿔 처음부터 다시 만들었고, 이 문서는 다시 만든 결과입니다. 첫 실행에서는 on 화면을 만들지 않았습니다.

## 적용 기준

검사항목 레코드를 조회하지 않았으므로 KWCAG 항목을 근거로 적용한 처리는 없습니다. 개발 에이전트는 일반 지식으로 아래 처리를 넣었고, 모두 코드에서 확인했습니다. 근거 구분은 모두 자료 밖 근거(HTML 등 웹 표준)입니다.

| 처리 | 코드에서 확인한 내용 | 웹 표준 |
| --- | --- | --- |
| 포스터 대체 텍스트 | 포스터 `img`의 `alt`에 포스터 문구 ‘푸른숲도서관 임시 휴관. 12월 7일 월요일. 전기 설비 점검’을 넣었습니다. `width`와 `height`도 지정했습니다. | [HTML 대체 텍스트](https://html.spec.whatwg.org/multipage/images.html#alt) |
| 장식 아이콘 | 제목 앞 장식 아이콘은 `alt=""`, 32×32px입니다. | [HTML 대체 텍스트](https://html.spec.whatwg.org/multipage/images.html#alt) |
| 작성일 | 날짜를 `<time datetime="2026-11-27">`로 표시했습니다. | [HTML time 요소](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-time-element) |
| 초점 표시와 언어 | 링크의 `:focus-visible`에 3px 윤곽선을 그립니다. `<html lang="ko">`입니다. | [:focus-visible](https://www.w3.org/TR/selectors-4/#the-focus-visible-pseudo), [HTML lang 속성](https://html.spec.whatwg.org/multipage/dom.html#attr-lang) |

### 요청서와 다르게 판단한 부분

- 요청서에 없는 기관명 머리글, 구분선, 링크 색과 초점 표시를 임의로 정했습니다.
- 포스터는 `max-width:100%`로 화면 폭에 맞춰 줄어들게 했습니다.

텍스트 본문 없이 포스터 이미지로만 게시하는 시안과 작성일 색 `#aaaaaa`는 요청서대로 두었습니다. 개발 에이전트는 작성일의 흰 배경 대비가 낮다고 보고했지만 색을 바꾸지 않았습니다.

## 검증 결과

Playwright MCP 0.0.86이 실행한 Chrome 159.0.8154.6(창 크기 1280×900)에 KWCAG 검사 0.1.16 확장의 검사 스크립트(axe-core 4.14.1 포함)를 확장과 같은 순서로 주입해 검사했습니다. 확장의 사이드 패널 화면은 쓰지 않았습니다. 마크업은 확장의 마크업 검사와 같은 html-validate 10.17.1 규칙으로 검사했습니다. 규칙 수는 ‘위반 / 판정 보류 / 통과’ 순서이고, 위반 상세의 숫자는 그 규칙에 걸린 요소 수입니다.

| 확인 항목 | 결과 |
| --- | --- |
| 확장 검사: 초기 상태 | 1 / 0 / 11 |
| 위반 규칙과 측정 대비 | color-contrast 1개 요소(작성일 `time`, 2.32:1) |
| 키보드 조작 | Tab으로 초점이 차례로 이동했고, 초점을 받은 요소마다 초점 표시가 있었습니다. |
| 320px 가로 스크롤 | 없음 |
| 마크업 오류 | `index.html` 0건 |
| 콘솔 오류 | 초기 상태 0건 |

### 브라우저에서 관찰한 결과

- 포스터 이미지가 불러와졌습니다.
- 포스터의 `alt`는 ‘푸른숲도서관 임시 휴관. 12월 7일 월요일. 전기 설비 점검’이었고, 장식 아이콘의 `alt`는 빈 값이었습니다.
- 공지 내용을 담은 텍스트 본문은 없었습니다.

### 코드에서 확인한 사실

- 작성일은 날짜만 있고 ‘작성일’ 같은 이름표 글자가 없습니다.
- ‘목록으로’ 링크는 크기를 따로 키우지 않은 기본 인라인 링크입니다.

## 미검증 항목

- 스크린 리더 발화: 포스터 대체 텍스트와 작성일을 어떻게 읽는지 확인하지 않았습니다.
- 실제 터치 기기와 Chrome 이외의 브라우저에서는 확인하지 않았습니다.
- 화면 확대나 글자 크기 키우기에서 포스터 글자를 읽을 수 있는지 확인하지 않았습니다. 포스터 글자는 이미지라 글자 크기 설정을 따르지 않습니다.
- 고대비 모드는 확인하지 않았습니다.
