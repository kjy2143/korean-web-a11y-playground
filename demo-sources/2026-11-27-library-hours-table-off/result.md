# 도서관 운영 시간 · 기본 개발 (off) 실행 결과

푸른숲도서관 분관 세 곳의 요일별 운영 시간과 휴관일을 표 하나로 비교하는 화면입니다. 국내 접근성 자료(KWCAG 2.2, NIA 제작기법)를 조회해 적용하는 개발 절차를 끈 상태에서 요청서대로 만들었습니다. 같은 요청서로 개선한 화면은 [접근성 자료 적용 (on)](/?demo=2026-11-27-library-hours-table-on)에 있습니다.

확장 검사에서 표 아래 ‘2026년 11월 기준’ 문구가 명도 대비 위반(2.32:1)으로 나왔습니다. 휴관 칸 4곳은 화면에서 연한 빨강 배경으로만 구분됩니다. ‘휴관’ 글자는 칸마다 들어 있지만 화면에서 숨긴 글자입니다. 브라우저 확인에서 ‘휴관’ 글자가 화면에 보이는 칸은 0곳이었습니다.

## 사용 방법

- 표에서 분관(행)과 요일(열)이 만나는 칸의 운영 시간을 읽습니다. 글자 없이 연한 빨강 배경인 칸이 휴관일입니다.
- 화면 폭이 좁으면 표 영역만 가로로 스크롤되도록 만들었습니다. 키보드로는 Tab으로 표 영역에 초점을 둔 뒤 방향키로 스크롤합니다.

## 요청서

개발 에이전트에게 준 ‘화면 요청서: 도서관 운영 시간’의 전문입니다.

> ### 공통 사항
>
> 가상의 기관 ‘푸른숲도서관’(전시 일정은 ‘푸른숲미술관’)의 화면입니다. HTML, CSS, JavaScript만 쓰고 외부 라이브러리와 CDN은 쓰지 않습니다. 모든 파일은 지정한 데모 폴더 안에 두고, 진입 페이지는 `index.html`입니다. 페이지 제목은 `<화면 이름> - 한국 웹 접근성 플레이그라운드`, 설명(meta description)은 요청서에 적은 문장을 씁니다. 데스크톱과 폭 320px 화면에서 모두 쓸 수 있어야 합니다. 결과 문서는 다른 담당자가 쓰므로 만들지 않습니다.
>
> ### 요청 내용
>
> 설명: 분관별 요일 운영 시간과 휴관일을 비교합니다.
>
> 분관 세 곳의 월요일~일요일 운영 시간을 표로 보여 줍니다. 중앙관은 월요일 휴관, 화~금 09:00–22:00, 토·일 09:00–18:00입니다. 숲속분관은 월요일 휴관, 화~일 10:00–19:00입니다. 어린이분관은 월·화요일 휴관, 수~일 10:00–18:00입니다.
>
> 디자인 시안: 첫 줄(요일)과 첫 칸(분관 이름)은 회색 배경에 굵은 글씨입니다. 휴관일 칸은 연한 빨강 배경으로 표시하고 시안처럼 글자는 넣지 않습니다. 좁은 화면에서는 표 영역만 가로로 스크롤합니다. 표 아래 ‘2026년 11월 기준’은 `#aaaaaa`로 작게 둡니다.

## 개발 조건

- 모델과 실행 도구: Claude Sonnet 5.5, Claude Code 2.1.332(헤드리스 실행)
- 실행 위치: 이 저장소 밖의 빈 폴더입니다. 이 저장소의 프로젝트 지침은 읽지 않았습니다.
- 개발 절차: 국내 접근성 자료를 조회해 적용하는 절차를 껐습니다. 개발 에이전트는 화면 요청서만 받았습니다. 절차의 설정을 확인하는 문서와 설정 값만 읽었고, 자료 목록과 검사항목 레코드는 한 번도 받지 않았습니다. 실행 기록에서 이 세션의 자료 조회가 0회임을 확인했습니다.
- 도구: 브라우저 도구와 MCP 서버가 없었고, 디자인 검사 플러그인을 껐습니다. 허용한 셸 명령은 `node`, `ls`, `cat`, `curl`, `mkdir`, `cp`입니다. 그 밖의 명령과 일부 복합 명령은 거부됐습니다. 이 세션에서 거부된 호출은 1건으로, `cat`의 출력을 파일로 보내 `index.html`을 쓰려던 명령이었습니다. 파일은 모두 만들어졌습니다. 개발 에이전트는 브라우저 렌더링을 확인하지 않고 마무리했다고 보고했습니다.
- 수정 요청: 조작 확인에서 기능 결함이 나오지 않아 수정 요청을 보내지 않았습니다.
- 보존: on 화면을 개발한 뒤에도 이 화면의 파일이 바뀌지 않았음을 해시로 확인했습니다.
- 재실행: 이 문서는 세 번째 실행의 결과입니다.
  1. 첫 실행: 다른 모델(Claude Opus 5.5)로 이 저장소 안에서 off 화면 13개를 만들었습니다. 13개 모두 확장 검사 위반이 0건이었습니다. 개발 에이전트들은 이 저장소의 프로젝트 지침과 일반 지식에 따라 시안을 접근성 기준에 맞춰 바꿨다고 보고했습니다. on 화면은 만들지 않았습니다.
  2. 두 번째 실행(2026-11-27 오후): 모델과 실행 위치를 바꿔 다시 만들었습니다. off 개발 에이전트 13개 중 12개가 절차의 설정을 읽는 명령에서 자료 목록(검사항목 33개의 제목과 주소)을 함께 받았습니다. on 13개는 모두 일괄 내려받기 명령이 거부됐고, 일부는 필수 항목의 본문을 끝까지 읽지 못했습니다.
  3. 세 번째 실행(이 문서, 2026-11-27 밤): 개발 절차를 ‘설정 확인’ 문서와 ‘절차’ 문서로 나눠 off 세션이 절차와 자료를 보지 않게 했습니다. 자료 조회 명령은 한 형태로 고정했습니다. 요청서는 두 번째 실행과 같은 확정본입니다. 화면은 처음부터 다시 만들었습니다.

## 적용 기준

검사항목 레코드를 조회하지 않았으므로 KWCAG 항목을 근거로 적용한 처리는 없습니다. 개발 에이전트는 일반 HTML 접근성 지식으로 아래 처리를 넣었고, 모두 코드에서 확인했습니다. 근거 구분은 모두 자료 밖 근거(HTML, WAI-ARIA 등 웹 표준)입니다.

| 처리 | 코드에서 확인한 내용 | 웹 표준 |
| --- | --- | --- |
| 표 제목 | 표에 `caption`(‘분관별 요일 운영 시간’)을 두고 `clip-path`로 화면에서만 숨겼습니다. | [HTML caption 요소](https://html.spec.whatwg.org/multipage/tables.html#the-caption-element) |
| 제목 셀 | 첫 줄 8칸(‘분관’과 요일 7개)은 `th scope="col"`, 첫 칸 분관 3칸은 `th scope="row"`입니다. 표는 `thead`와 `tbody`로 나눴습니다. | [HTML th scope 속성](https://html.spec.whatwg.org/multipage/tables.html#attr-th-scope) |
| 휴관 칸 | 휴관 칸 4곳에 `<span class="sr-only">휴관</span>`을 넣었습니다. `.sr-only`는 글자를 화면에서 숨기는 규칙입니다. | 해당 없음 |
| 스크롤 영역 | 표를 감싼 `div`에 `role="region"`, `aria-labelledby="table-caption"`, `tabindex="0"`을 달았습니다. `:focus-visible`에서 `3px solid #1a56c4` 윤곽선을 그립니다. 표의 최소 폭은 640px입니다. | [region 역할](https://www.w3.org/TR/wai-aria-1.2/#region), [aria-labelledby](https://www.w3.org/TR/wai-aria-1.2/#aria-labelledby), [HTML tabindex](https://html.spec.whatwg.org/multipage/interaction.html#attr-tabindex) |
| 기본 언어 | `<html lang="ko">`입니다. | [HTML lang 속성](https://html.spec.whatwg.org/multipage/dom.html#attr-lang) |

### 요청서와 다르게 판단한 부분

- 휴관 칸에 글자를 넣지 않는 시안은 화면에서 지켰고, 칸 안에 숨김 글자 ‘휴관’을 넣었습니다. 개발 에이전트는 색만으로는 휴관을 알 수 없어서라고 보고했습니다.
- 요청서의 화면 이름을 `h1`로, 설명 문장을 본문 첫 문단으로 넣었습니다. 기관명 ‘푸른숲도서관’을 담은 머리글도 더했습니다.
- 시안에 값이 없는 색은 개발 에이전트가 정했습니다. 제목 셀의 회색은 `#e6e6e6`, 휴관 칸의 연한 빨강은 `#fbdcdc`입니다.

‘2026년 11월 기준’의 `#aaaaaa`는 요청서대로 두었습니다. 개발 에이전트는 흰 배경에서 대비가 약 2.3:1이라 읽기 어려울 수 있다고 보고했습니다. 색 지정이 요청서 사항이어서 바꾸지 않았다고 적었습니다.

## 검증 결과

Playwright 1.66 스크립트가 실행한 헤드리스 Chrome 158.0.8127.37(창 크기 1280×900)에 KWCAG 검사 0.1.17 확장의 검사 스크립트(axe-core 4.14.1 포함)를 확장과 같은 순서로 주입해 검사했습니다. 확장의 사이드 패널 화면은 쓰지 않았습니다. 마크업은 확장의 마크업 검사와 같은 html-validate 10.17.1 규칙으로 검사했습니다. 키보드 조작은 사람이 아니라 스크립트가 보냈습니다. 규칙 수는 ‘위반 / 판정 보류 / 통과’ 순서이고, 요소 수가 아니라 규칙 종류 수입니다.

| 확인 항목 | 결과 |
| --- | --- |
| 확장 검사: 초기 상태 | 1 / 0 / 18 |
| 위반 규칙과 측정 대비 | `color-contrast` 1개 요소(`.basis`, 전경 `#aaaaaa`, 배경 `#ffffff`, 13px, 2.32:1) |
| 휴관 칸 | ‘휴관’ 글자가 든 칸 4곳, 그 글자가 화면에 보이는 칸 0곳 |
| 키보드 조작 | Tab 정지점은 표 스크롤 영역 1곳이고 초점 표시가 있었습니다. |
| 320px 가로 스크롤 | 페이지 가로 스크롤 없음 |
| 마크업 오류 | `index.html` 0건 |
| 콘솔 오류 | 초기 상태 0건 |

### 브라우저에서 관찰한 결과

- 표에는 `caption` ‘분관별 요일 운영 시간’이 있었고 본문은 분관 3행이었습니다.
- `th`는 11개였고 `scope`는 col 8개, row 3개였습니다.
- ‘휴관’ 글자가 든 칸은 4곳이었습니다. 그 글자가 화면에 보이는 칸은 없었습니다.
- 스크롤 영역은 `tabindex="0"`이었고 `aria-labelledby`가 `table-caption`을 가리켰습니다.
- Tab을 한 번 누르면 표 스크롤 영역이 초점을 받았습니다. 다음 Tab에서는 초점을 받는 요소가 더 없었습니다.
- 확장 검사의 제목 목록에는 `h1` ‘도서관 운영 시간’과 스크롤 영역의 영역 제목 ‘분관별 요일 운영 시간’이 수집됐습니다.

### 코드에서 확인한 사실

- 휴관 칸 4곳(중앙관 월요일, 숲속분관 월요일, 어린이분관 월·화요일)과 나머지 칸의 운영 시간은 요청서와 같습니다.
- 휴관 칸은 `td.closed`이고 배경은 `#fbdcdc`입니다. 칸 안의 ‘휴관’은 `.sr-only`(`position: absolute`, 폭과 높이 1px, `clip-path: inset(50%)`)로 숨깁니다.
- 제목 셀은 배경 `#e6e6e6`, `font-weight: 700`입니다. 칸 테두리는 `1px solid #ccc`입니다.
- 기준일 문구 `.basis`는 `color: #aaaaaa`, `font-size: 0.8125rem`입니다.
- `overflow-x: auto`는 표 영역(`.table-scroll`)에만 있습니다. 표의 최소 폭이 640px이라, 폭이 그보다 좁으면 표 영역이 스크롤되도록 작성돼 있습니다.
- 파일은 `index.html`과 `style.css` 두 개이고 스크립트는 없습니다.

## 미검증 항목

- 스크린 리더 발화: 표 제목, 행·열 제목과 칸의 연결, 휴관 칸의 숨김 글자를 어떻게 읽는지 확인하지 않았습니다.
- 실제 터치 기기와 Chrome 이외의 브라우저에서는 확인하지 않았습니다.
- 320px에서 표 영역이 실제로 가로 스크롤되는지, 방향키로 스크롤되는지는 기록하지 않았습니다.
- 초점 표시는 있고 없음만 기록했습니다. 윤곽선의 색과 잘림 여부는 기록하지 않았습니다.
- 고대비 모드에서 배경색이 사라질 때 휴관 칸을 구분할 수 있는지 확인하지 않았습니다.
