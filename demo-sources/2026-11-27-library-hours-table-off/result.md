# 도서관 운영 시간 · 기본 개발 (off) 실행 결과

푸른숲도서관 분관 세 곳의 요일별 운영 시간과 휴관일을 표 하나로 비교하는 화면입니다. 국내 접근성 자료(KWCAG 2.2, NIA 제작기법)를 조회해 적용하는 개발 절차를 끈 상태에서 요청서대로 만들었습니다. 같은 요청서로 개선한 화면은 [접근성 자료 적용 (on)](/?demo=2026-11-27-library-hours-table-on)에 있습니다.

확장 검사에서 표 아래 ‘2026년 11월 기준’ 문구가 명도 대비 위반(2.32:1)으로 나왔습니다. 휴관 칸은 화면에서 연한 빨강 배경으로만 구분되고, ‘휴관’ 글자는 보조기술용 숨김 텍스트로만 들어 있습니다.

## 사용 방법

- 표에서 분관(행)과 요일(열)이 만나는 칸의 운영 시간을 읽습니다. 연한 빨강 칸이 휴관일입니다.
- 화면 폭이 좁으면 표 영역만 가로로 스크롤됩니다. 키보드로는 Tab으로 표 영역에 초점을 둔 뒤 방향키로 스크롤합니다.

## 요청서

개발 에이전트에게 준 ‘화면 요청서: 도서관 운영 시간’의 전문입니다.

> ### 공통 사항
>
> 가상의 기관 ‘푸른숲도서관’(전시 일정은 ‘푸른숲미술관’)의 화면입니다. HTML, CSS, JavaScript만 쓰고 외부 라이브러리와 CDN은 쓰지 않습니다. 모든 파일은 지정한 데모 폴더 안에 두고, 진입 페이지는 `index.html`입니다. 페이지 제목은 `<화면 이름> - 한국 웹 접근성 플레이그라운드`, 설명(meta description)은 요청서에 적은 문장을 씁니다. 데스크톱과 폭 320px 화면에서 모두 쓸 수 있어야 합니다. 결과 문서는 다른 담당자가 쓰므로 만들지 않습니다.
>
> ### 요청 내용
>
> 설명: 분관별 요일 운영 시간과 휴관일을 비교합니다.
>
> 분관 세 곳의 월요일~일요일 운영 시간을 표로 보여 줍니다. 중앙관은 월요일 휴관, 화~금 09:00–22:00, 토·일 09:00–18:00입니다. 숲속분관은 월요일 휴관, 화~일 10:00–19:00입니다. 어린이분관은 월·화요일 휴관, 수~일 10:00–18:00입니다.
>
> 디자인 시안: 첫 줄(요일)과 첫 칸(분관 이름)은 회색 배경에 굵은 글씨입니다. 휴관일 칸은 연한 빨강 배경으로 표시하고 시안처럼 글자는 넣지 않습니다. 좁은 화면에서는 표 영역만 가로로 스크롤합니다. 표 아래 ‘2026년 11월 기준’은 `#aaaaaa`로 작게 둡니다.

## 개발 조건

- 모델과 실행 도구: Claude Sonnet 5.5, Claude Code 2.1.332(헤드리스 실행)
- 실행 위치: 이 저장소 밖의 빈 폴더입니다. 그래서 이 저장소의 프로젝트 지침은 읽지 않았습니다.
- 개발 절차: 국내 접근성 자료를 조회해 적용하는 절차를 껐습니다.
- 지시: 요청서 전문을 주고, 질문하지 말고 구현을 마친 뒤 만든 파일과 판단이 필요했던 점을 보고하게 했습니다.
- 도구: 브라우저 도구와 MCP 서버가 없었고, 디자인 검사 플러그인을 껐습니다. 허용한 셸 명령 범위가 좁아 일부 복합 명령이 거부됐습니다. 개발 에이전트는 화면을 브라우저로 열어 보지 않았다고 보고했습니다.
- 수정 요청: 이 화면에서 기능 결함을 찾지 못해 수정 요청을 보내지 않았습니다.
- 보존: on 화면을 개발한 뒤에도 이 화면의 파일이 바뀌지 않았음을 해시로 확인했습니다.
- 자료 목록: 개발 에이전트는 개발 절차의 설정을 읽는 셸 명령과 같은 명령에서 국내 접근성 자료의 목록 페이지(KWCAG 2.2 검사항목 33개의 제목과 레코드 주소)를 한 번 받았습니다. 설정이 꺼져 있음을 확인한 뒤에는 검사항목 레코드를 읽지 않았습니다.
- 재실행: 처음에는 다른 모델(Claude Opus 5.5)로 이 저장소 안에서 off 화면 13개를 만들었습니다. 13개 모두 확장 검사 위반이 0건이었고, 개발 에이전트들은 이 저장소의 프로젝트 지침(AGENTS.md)과 일반 지식에 따라 요청서의 시안을 접근성 기준에 맞춰 바꿨다고 보고했습니다. 프로젝트 지침과 모델의 영향을 줄이려고 모델과 실행 위치를 바꿔 처음부터 다시 만들었고, 이 문서는 다시 만든 결과입니다. 첫 실행에서는 on 화면을 만들지 않았습니다.

## 적용 기준

검사항목 레코드를 조회하지 않았으므로 KWCAG 항목을 근거로 적용한 처리는 없습니다. 개발 에이전트는 일반 HTML 접근성 지식으로 아래 처리를 넣었고, 모두 코드에서 확인했습니다. 근거 구분은 모두 자료 밖 근거(HTML, WAI-ARIA 등 웹 표준)입니다.

| 처리 | 코드에서 확인한 내용 | 웹 표준 |
| --- | --- | --- |
| 표 제목 | 표에 `caption`(‘푸른숲도서관 분관별 요일 운영 시간’)을 두고 화면에서만 숨겼습니다. | [HTML caption 요소](https://html.spec.whatwg.org/multipage/tables.html#the-caption-element) |
| 제목 셀 | 첫 줄 요일 8칸은 `th scope="col"`, 첫 칸 분관 3칸은 `th scope="row"`입니다. | [HTML th scope 속성](https://html.spec.whatwg.org/multipage/tables.html#attr-th-scope) |
| 휴관 칸 | 휴관 칸 4곳에 화면에서 숨긴 글자 ‘휴관’을 넣었습니다. | 해당 없음 |
| 스크롤 영역 | 표를 감싼 영역에 `role="region"`, `aria-labelledby`(표 제목), `tabindex="0"`을 달고 `:focus-visible` 윤곽선을 그립니다. 표의 최소 폭은 640px입니다. | [region 역할](https://www.w3.org/TR/wai-aria-1.2/#region), [HTML tabindex](https://html.spec.whatwg.org/multipage/interaction.html#attr-tabindex) |
| 기본 언어 | `<html lang="ko">`입니다. | [HTML lang 속성](https://html.spec.whatwg.org/multipage/dom.html#attr-lang) |

### 요청서와 다르게 판단한 부분

- 휴관 칸에 글자를 넣지 않는 시안은 화면에서 지켰고, 칸 안에 숨김 텍스트 ‘휴관’을 넣었습니다. 개발 에이전트는 색만으로 휴관을 알리는 문제를 막으려는 판단이라고 보고했습니다.
- 요청서에 없는 제목(`h1`)과 안내 문장 한 줄을 더했습니다.

‘2026년 11월 기준’의 `#aaaaaa`는 요청서대로 두었습니다. 개발 에이전트는 흰 배경에서 대비가 낮다고 보고하고, 색을 바꿀지는 요청자가 정해야 한다고 남겼습니다.

## 검증 결과

Playwright MCP 0.0.86이 실행한 Chrome 159.0.8154.6(창 크기 1280×900)에 KWCAG 검사 0.1.16 확장의 검사 스크립트(axe-core 4.14.1 포함)를 확장과 같은 순서로 주입해 검사했습니다. 확장의 사이드 패널 화면은 쓰지 않았습니다. 마크업은 확장의 마크업 검사와 같은 html-validate 10.17.1 규칙으로 검사했습니다. 규칙 수는 ‘위반 / 판정 보류 / 통과’ 순서이고, 위반 상세의 숫자는 그 규칙에 걸린 요소 수입니다.

| 확인 항목 | 결과 |
| --- | --- |
| 확장 검사: 초기 상태 | 1 / 0 / 18 |
| 위반 규칙과 측정 대비 | color-contrast 1개 요소(`.note`, 2.32:1) |
| 키보드 조작 | Tab으로 초점이 차례로 이동했고, 초점을 받은 요소마다 초점 표시가 있었습니다. |
| 320px 가로 스크롤 | 페이지 가로 스크롤 없음 |
| 마크업 오류 | `index.html` 0건 |
| 콘솔 오류 | 초기 상태 0건 |

### 브라우저에서 관찰한 결과

- 표는 제목 행 하나와 분관 3행으로 나타났습니다.
- `th`는 11개였고 모두 `scope`(col 또는 row)가 있었습니다. 표에는 `caption`이 있었습니다.
- 휴관 칸 4곳에 텍스트 ‘휴관’이 있었습니다.
- 스크롤 영역은 `role="region"`, `tabindex="0"`이었습니다.

### 코드에서 확인한 사실

- 휴관 칸 4곳(중앙관 월요일, 숲속분관 월요일, 어린이분관 월·화요일)은 요청서의 휴관일과 같습니다. 칸 안의 ‘휴관’은 `.sr-only`로 화면에서 숨깁니다.
- 표 테두리 색은 `#bbb`입니다.
- 표 영역에만 `overflow-x: auto`가 있어, 폭이 640px보다 좁으면 표 영역이 스크롤되도록 작성돼 있습니다.

## 미검증 항목

- 스크린 리더 발화: 표 제목, 행·열 제목과 칸의 연결, 휴관 칸의 숨김 텍스트를 어떻게 읽는지 확인하지 않았습니다.
- 실제 터치 기기와 Chrome 이외의 브라우저에서는 확인하지 않았습니다.
- 320px에서 표 영역이 실제로 가로 스크롤되는지, 방향키로 스크롤되는지는 기록하지 않았습니다.
- 고대비 모드에서 배경색이 사라질 때 휴관 칸을 구분할 수 있는지 확인하지 않았습니다.
