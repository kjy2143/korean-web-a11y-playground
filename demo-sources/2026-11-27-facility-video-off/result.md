# 안내 데스크 호출 벨 · 기본 개발 (off) 실행 결과

안내 데스크 호출 벨 소리를 영상과 자막으로 알려 주는 이용 방법 페이지입니다. 국내 접근성 자료(KWCAG 2.2, NIA 제작기법)를 조회해 적용하는 개발 절차를 끈 상태에서 화면 요청서만으로 만들었습니다. 확장 검사에서 위반 규칙과 판정 보류 규칙은 없었습니다. 스크립트는 페이지를 열 때 소리와 함께 재생을 시도합니다. 확인에 쓴 브라우저는 사용자 조작이 있어야 재생을 허용하는 설정이어서 영상이 정지 상태로 시작했습니다. 재생 중에는 가운데 버튼의 불투명도가 0이었습니다.

같은 요청서로 접근성 자료를 적용해 개선한 화면은 [접근성 자료 적용 (on)](/?demo=2026-11-27-facility-video-on)에서 볼 수 있습니다.

## 사용 방법

1. 페이지를 열면 제목, 벨 사용법 문단, 영상이 보입니다. 스크립트가 페이지를 연 직후 소리와 함께 재생을 시도합니다.
2. 브라우저가 소리 있는 자동 재생을 막으면 영상 가운데에 재생 버튼이 남습니다. 화면에서 숨긴 상태 영역에는 ‘브라우저 정책으로 자동 재생되지 않았습니다. 재생 버튼을 눌러 주세요.’가 들어갑니다.
3. 가운데 버튼이나 영상을 누르면 재생과 일시정지가 바뀝니다.
4. 재생 중에는 가운데 버튼이 투명해집니다. 영상 영역에 마우스를 올리거나 버튼에 키보드 초점이 오면 다시 보입니다.
5. 한국어 자막이 기본으로 켜져 ‘[안내 데스크 호출 벨이 한 번 울림]’, ‘[안내 데스크 호출 벨이 두 번 울림]’을 표시합니다.

## 요청서

‘화면 요청서: 안내 데스크 호출 벨’의 전문입니다.

> ### 공통 사항
>
> 가상의 기관 ‘푸른숲도서관’(전시 일정은 ‘푸른숲미술관’)의 화면입니다. HTML, CSS, JavaScript만 쓰고 외부 라이브러리와 CDN은 쓰지 않습니다. 모든 파일은 지정한 데모 폴더 안에 두고, 진입 페이지는 `index.html`입니다. 페이지 제목은 `<화면 이름> - 한국 웹 접근성 플레이그라운드`, 설명(meta description)은 요청서에 적은 문장을 씁니다. 데스크톱과 폭 320px 화면에서 모두 쓸 수 있어야 합니다. 결과 문서는 다른 담당자가 쓰므로 만들지 않습니다.
>
> ### 요청 내용
>
> 설명: 안내 데스크 호출 벨 소리를 영상으로 알려 줍니다.
>
> 안내 데스크 이용 방법 페이지입니다. 제목과 설명 한 문단(‘안내 데스크에 직원이 없을 때 벨을 누르세요. 한 번 울리면 일반 문의, 두 번 울리면 긴급 문의입니다.’), 영상 한 편이 있습니다. 제공 자산은 영상 `desk-chimes.mp4`(약 8초, 벨이 한 번 울리고 이어서 두 번 울림)와 자막 파일 `desk-chimes.vtt`입니다.
>
> 디자인 시안: 페이지에 들어오면 영상을 소리와 함께 자동 재생합니다. 브라우저 기본 컨트롤 막대는 숨기고 영상 가운데에 재생·일시정지 아이콘 버튼만 둡니다. 재생 중에는 아이콘을 숨기고 마우스를 올리면 보입니다. 영상 아래 캡션 ‘안내 데스크 호출 벨’은 `#aaaaaa`입니다.

## 개발 조건

- 개발 절차: 국내 접근성 자료를 조회해 적용하는 절차를 끄고 화면 요청서만 주었습니다. 개발 에이전트는 절차의 설정을 확인하는 문서와 설정 값만 읽었습니다. 자료 목록과 검사항목 레코드는 한 번도 받지 않았고, 실행 기록에서 자료 조회가 0회임을 확인했습니다.
- 모델과 실행 방식: Claude Sonnet 5.5를 Claude Code 2.1.332에서 헤드리스로 실행했습니다.
- 작업 위치: 이 저장소 밖의 빈 폴더에서 실행했습니다. 이 저장소의 프로젝트 지침은 읽지 않았습니다.
- 도구: 브라우저 도구와 MCP 서버가 없었습니다. 디자인 검사 플러그인은 껐습니다. 개발 에이전트는 코드와 명령으로만 확인했습니다.
- 셸 명령: 허용한 명령은 `node`, `ls`, `cat`, `curl`, `mkdir`, `cp`입니다. 그 밖의 명령과 일부 복합 명령은 거부됐습니다. 이 세션에서 거부된 호출은 1건으로, `cat`의 출력을 파일로 보내 `index.html`을 쓰려던 명령이었습니다. 파일은 모두 만들어졌습니다.
- 개발 중 확인: 개발 에이전트는 브라우저에서 열어 보거나 자동 재생을 실행해 보지는 않았다고 보고했습니다.
- 제공 자산: 영상 `desk-chimes.mp4`와 자막 `desk-chimes.vtt`를 그대로 연결했습니다.
- 수정 요청: 브라우저 확인에서 기능 결함을 찾지 못해 수정 요청을 보내지 않았습니다.
- 보존: on 화면을 개발한 뒤에도 이 화면의 파일이 바뀌지 않았음을 해시로 확인했습니다.
- 재실행: 이 문서는 세 번째 실행의 결과입니다. 첫 실행에서는 다른 모델(Claude Opus 5.5)로 이 저장소 안에서 off 화면 13개를 만들었습니다. 13개 모두 확장 검사 위반이 0건이었고, 개발 에이전트들은 이 저장소의 프로젝트 지침과 일반 지식에 따라 시안을 접근성 기준에 맞춰 바꿨다고 보고했습니다. 첫 실행에서는 on 화면을 만들지 않았습니다. 두 번째 실행(2026-11-27 오후)에서는 모델과 실행 위치를 바꿔 다시 만들었습니다. 이때 off 개발 에이전트 13개 중 12개가 절차의 설정을 읽는 명령에서 자료 목록(검사항목 33개의 제목과 주소)을 함께 받았습니다. on 13개는 모두 일괄 내려받기 명령이 거부됐고, 일부는 필수 항목의 본문을 끝까지 읽지 못했습니다. 세 번째 실행(2026-11-27 밤)에서는 개발 절차를 설정 확인 문서와 절차 문서로 나눠 off 세션이 절차와 자료를 보지 않게 했고, 자료 조회 명령을 한 형태로 고정했습니다. 요청서는 두 번째 실행과 같은 확정본이고, 화면은 처음부터 다시 만들었습니다.

## 적용 기준

검사항목 레코드를 조회하지 않았으므로 KWCAG 항목을 근거로 적용한 처리는 없습니다. 아래 목록은 개발 에이전트가 일반 지식으로 넣은 처리를 코드에서 확인한 것입니다.

### 자료 밖 근거(HTML, WAI-ARIA)

- 자막 파일을 `track kind="captions"`로 연결하고 `default`로 기본 표시했습니다. [HTML track 요소](https://html.spec.whatwg.org/multipage/media.html#the-track-element)
- 재생·일시정지는 영상 가운데의 `button` 하나로 만들었습니다. 버튼 이름은 `aria-label`로 주고, 상태에 따라 ‘재생’, ‘일시정지’, ‘다시 재생’으로 바꿉니다. [HTML button 요소](https://html.spec.whatwg.org/multipage/form-elements.html#the-button-element), [WAI-ARIA 1.2 aria-label](https://www.w3.org/TR/wai-aria-1.2/#aria-label)
- 버튼 안의 아이콘 SVG는 `aria-hidden="true"`로 숨겼습니다. [WAI-ARIA 1.2 aria-hidden](https://www.w3.org/TR/wai-aria-1.2/#aria-hidden)
- 재생 중 투명하게 한 버튼은 마우스 올림뿐 아니라 `:focus-visible` 상태에서도 보입니다. 초점 윤곽선은 노란(`#ffd54a`) 3px입니다. [Selectors Level 4의 :focus-visible](https://www.w3.org/TR/selectors-4/#the-focus-visible-pseudo)
- 자동 재생이 거부되면 화면에서 숨긴 `role="status"` 문단에 안내 문구를 넣습니다. [WAI-ARIA 1.2 status 역할](https://www.w3.org/TR/wai-aria-1.2/#status)
- `video`에 `aria-label`로 ‘안내 데스크 호출 벨 소리 안내 영상’이라는 이름을 주었습니다.
- 영상과 캡션을 `figure`와 `figcaption`으로 묶었습니다. [HTML figure 요소](https://html.spec.whatwg.org/multipage/grouping-content.html#the-figure-element)
- 버튼의 투명도 전환 효과는 동작 줄이기를 설정하지 않은 경우에만 넣습니다. [Media Queries Level 5의 prefers-reduced-motion](https://www.w3.org/TR/mediaqueries-5/#prefers-reduced-motion)

### 요청서와 다르게 판단한 부분

- 소리 있는 자동 재생은 요청대로 시도합니다. 개발 에이전트는 대부분의 브라우저가 이를 막는다고 보고, 막히면 재생 버튼이 보이는 상태로 두고 스크린 리더용 상태 문구로 안내하게 했습니다.
- 브라우저 기본 컨트롤 막대는 시안대로 숨겼습니다. 가운데 버튼은 시안의 마우스 올림 외에 키보드 초점이 갈 때도 보이게 했습니다. 보고서는 마우스 없이 쓰는 사람이 일시정지할 수단이 없어지는 것을 막기 위해서라고 적었습니다.
- 영상을 클릭해도 재생과 일시정지가 바뀌게 했습니다. 보고서는 터치 화면에는 마우스를 올리는 동작이 없기 때문이라고 적었습니다.
- 자막 트랙을 기본으로 켰습니다. 보고서는 소리로 구분하는 안내 영상이라 자막이 필수라고 판단했다고 적었습니다.
- 캡션 `#aaaaaa`는 흰 배경에서 대비가 부족하다고 보고, 캡션을 영상과 같은 어두운 패널(`#111`) 위에 놓아 색을 그대로 두었습니다.

## 검증 결과

확장 검사는 Playwright 1.66 스크립트가 실행한 헤드리스 Chrome 158.0.8127.37(창 크기 1280×900)에서 했습니다. KWCAG 검사 0.1.17 확장의 검사 스크립트(axe-core 4.14.1 포함)를 확장과 같은 순서로 페이지에 주입했고, 확장의 사이드 패널 화면은 쓰지 않았습니다. 마크업은 확장의 마크업 검사와 같은 html-validate 10.17.1 규칙으로 검사했습니다. 마우스와 키보드 조작은 사람이 아니라 스크립트가 보냈습니다. 규칙 수는 ‘위반 / 판정 보류 / 통과’ 순서이고 요소 수가 아니라 규칙 종류 수입니다. 재생과 정지 조작을 확인할 때는 브라우저를 사용자 조작이 있어야 재생을 허용하는 자동 재생 정책으로 실행했습니다.

### 브라우저에서 관찰한 결과

- 페이지를 연 직후 영상은 정지 상태였습니다. 이 결과는 위에 적은 자동 재생 정책에 따른 것입니다. 영상은 음소거 상태가 아니었고, `autoplay` 속성과 `controls` 속성은 없었습니다.
- 상태 영역에 ‘브라우저 정책으로 자동 재생되지 않았습니다. 재생 버튼을 눌러 주세요.’가 들어 있었습니다.
- 한국어 자막 트랙(`captions`)이 표시 상태였습니다.
- 처음 버튼 이름은 ‘재생’이었습니다. 버튼을 클릭하자 영상이 재생됐고 이름이 ‘일시정지’로 바뀌었습니다.
- 버튼에 초점을 두고 Enter를 누르자 영상이 멈췄고 이름이 ‘재생’으로 돌아왔습니다. 초점은 버튼에 남았습니다.
- 재생을 시작하고 0.9초 뒤 버튼의 계산된 `opacity`는 0이었습니다. 마우스를 올리지 않고 버튼에 초점도 두지 않은 상태에서 잰 값입니다.
- Tab 정지점은 재생 버튼 하나였고 초점 표시가 있었습니다.
- 폭 320px에서 페이지 가로 스크롤이 없었습니다.
- 마크업 검사 오류는 0건이었습니다.
- 초기 상태의 콘솔 오류와 조작 중 페이지 오류는 0건이었습니다.

### 코드에서 확인한 사실

- `video`에 `autoplay` 속성은 없습니다. 스크립트가 페이지를 연 직후 `play()`를 호출하고, 재생이 거부되면 버튼 상태를 다시 맞춘 뒤 상태 문구를 넣습니다. `preload`는 `auto`입니다.
- 상태 문구가 들어가는 문단은 `role="status"`이고 화면에서 숨기는 클래스가 붙어 있습니다.
- 재생 중 버튼은 `opacity`만 0으로 바뀝니다. 영상 영역에 마우스를 올리거나 버튼이 `:focus-visible` 상태이면 1이 됩니다.
- 영상이 끝나면 버튼 이름을 ‘다시 재생’으로 바꿉니다.
- 버튼은 64×64px이고, 폭 360px 이하에서는 56×56px입니다.
- 자막 파일은 1.0~3.4초에 ‘[안내 데스크 호출 벨이 한 번 울림]’, 4.6~7.2초에 ‘[안내 데스크 호출 벨이 두 번 울림]’을 표시합니다.
- 캡션 `figcaption`은 `#111` 배경 위 `#aaaaaa` 글자입니다.
- 이번 실행에서 만든 페이지의 제목(`title`)은 ‘안내 데스크 호출 벨 - 한국 웹 접근성 플레이그라운드’이고 `h1`은 ‘안내 데스크 호출 벨’입니다.

## 미검증 항목

- 자동 재생을 허용하는 브라우저 설정에서 페이지를 열면 소리가 바로 재생되는지 확인하지 않았습니다.
- 재생 중 영상에 마우스를 올리거나 버튼에 키보드 초점을 두었을 때 버튼이 다시 보이는지 브라우저에서 확인하지 않았습니다.
- Space 키 조작, Enter로 재생을 시작하는 조작, 영상 영역을 눌러 재생과 일시정지를 바꾸는 조작은 확인하지 않았습니다.
- 영상이 끝난 뒤 버튼 이름이 ‘다시 재생’으로 바뀌고 다시 재생되는지 확인하지 않았습니다.

- 실제 터치 기기에서 재생 중 투명해진 버튼으로 일시정지할 수 있는지 확인하지 않았습니다.
- 영상의 깜빡임 여부와 자막 시간이 실제 벨 소리와 맞는지 확인하지 않았습니다.
- 캡션 글자의 측정 대비는 기록에 없습니다. 확장 검사에서 `color-contrast` 위반은 없었습니다.
- Chrome 외 브라우저와 화면 확대 상태는 확인하지 않았습니다.
