# 열람실 좌석 선택 · 기본 개발 (off) 실행 결과

푸른숲도서관 열람실의 빈 좌석을 골라 예약해 보는 데모입니다. [접근성 자료 적용 (on) 결과](/?demo=2026-11-28-reading-seat-selection-on)와 비교할 수 있습니다.

## 사용 방법

A2와 B3은 처음부터 예약된 자리입니다. A1을 선택하거나 ‘선택 해제’를 누릅니다. B1을 선택해 ‘예약하기’를 실행하면 완료 문구가 표시되고 B1을 다시 선택할 수 없습니다. 새로고침하면 최초 상태로 돌아옵니다.

## 요청서

> # 화면 요청서: 열람실 좌석 선택
>
> ### 공통 사항
>
> 가상의 기관 ‘푸른숲도서관’의 화면입니다. HTML, CSS, JavaScript만 쓰고 외부 라이브러리와 CDN은 쓰지 않습니다. 모든 파일은 지정한 데모 폴더 안에 두고, 진입 페이지는 index.html입니다. 페이지 제목은 ‘열람실 좌석 선택 - 한국 웹 접근성 플레이그라운드’, 설명(meta description)은 요청서에 적은 문장을 씁니다. 데스크톱과 폭 320px 화면에서 모두 쓸 수 있어야 합니다. 결과 문서는 다른 담당자가 쓰므로 만들지 않습니다.
>
> ### 요청 내용
>
> 설명: 푸른숲도서관 열람실의 빈 좌석을 선택하고 예약합니다.
>
> 좌석을 A1·A2·A3, B1·B2·B3 두 줄로 표시합니다. A2와 B3은 이미 예약된 좌석입니다. 남은 좌석 중 하나를 고르면 선택한 좌석 번호가 표시됩니다. 같은 자리나 다른 자리를 다시 선택할 수 있습니다. ‘선택 해제’로 선택을 지우고, ‘예약하기’로 선택한 좌석을 예약할 수 있습니다. 선택 전에는 두 조작을 사용할 수 없도록 합니다. 예약에 성공하면 완료 안내를 표시하고, 좌석이 예약 상태로 바뀌어 다시 선택되지 않아야 합니다. 실제 예약 서버는 연결하지 않습니다.
>
> 디자인 시안: 좌석 배치가 먼저 눈에 들어오도록 좌석 버튼에는 좌석 번호를 중심으로 표시하고, 선택 가능·이미 예약·현재 선택 상태를 색으로도 구분합니다. 배치도 옆이나 아래에 상태 범례를 둡니다. 예약 영역에는 선택 좌석과 버튼을 함께 둡니다.

## 개발 조건

Codex CLI 0.163.0와 `gpt-6.1-terra`을 두 개발 단계에 사용했습니다. 저장소 밖의 빈 폴더에서 기본 화면을 만든 뒤 같은 요청서와 해당 소스로 개선을 시작했습니다. 처음 개선한 화면을 검사한 다음 재현 절차를 같은 개선 세션에 보냈습니다. 최초 요청서와 기본 개발 파일의 SHA-256이 검증 후에도 일치했습니다.

## 적용 기준

개발 실행 기록에서 KWCAG 검사항목 자료를 조회한 호출은 확인되지 않았습니다. 기본 버튼, 가시 상태 문구와 `aria-pressed`를 초기 구현에서 확인했습니다. 구현에 사용한 자료 밖 근거는 HTML과 WAI-ARIA입니다. [WAI-ARIA aria-pressed](https://www.w3.org/TR/wai-aria-1.2/#aria-pressed)

## 검증 결과

Chrome 158.0.8127.37에서 KWCAG 검사 0.1.17의 사이드 패널로 검사했습니다. 초기 화면, A1을 클릭한 뒤 포인터를 둔 화면, B1 예약을 마친 화면을 비교했습니다. 각 검사 전에는 상태 변화가 끝날 시간을 두었습니다.

| 화면 상태 | 기본 개발 (off) | 접근성 자료 적용 (on), 첫 검사 | 접근성 자료 적용 (on), 최종 검사 |
| --- | --- | --- | --- |
| 초기 | 위반 0건, 판정 보류 1건 | 위반 0건, 판정 보류 1건 | 위반 0건, 판정 보류 0건 |
| A1 선택 후 포인터 유지 | 위반 2건, 판정 보류 2건 | 위반 2건, 판정 보류 2건 | 위반 0건, 판정 보류 0건 |
| B1 예약 완료 | 위반 0건, 판정 보류 1건 | 위반 0건, 판정 보류 1건 | 위반 0건, 판정 보류 0건 |

### 브라우저에서 관찰한 결과

- 선택 상태에서 두 버전의 브라우저 계산 색상으로 명도 대비를 계산했습니다. 기본 개발은 1.10:1, 최종 개선본은 7.72:1였습니다. 기본 개발과 첫 개선본에서는 확장이 A1 번호와 ‘현재 선택’ 문구를 각각 위반으로 표시했습니다. [5.4.3 텍스트 콘텐츠의 명도 대비](https://kwcag-docs.fe4all.dev/browse#v1/criteria/kwcag-5.4.3.json)
- 마우스로 A1 선택·해제, B1 예약과 예약된 좌석 재선택 시도를 확인했습니다. 두 화면에서 Tab으로 A1에 초점을 두고 Enter로 선택할 수 있었습니다. 양쪽 모두 320px 화면에서 페이지 전체가 가로로 넘치지 않았습니다.
- 기본 개발에서 예약 후 초점은 ‘좌석 배치도’로 갔습니다. 최종 개선본에서 선택 해제 후에는 A1으로, 예약 후에는 완료 메시지로 갔습니다.

### 코드에서 확인한 사실

좌석은 기본 버튼으로 구현돼 있습니다. 예약한 좌석과 선택 전 예약·해제 버튼에는 `disabled` 상태가 적용됩니다. 선택 상태는 텍스트와 `aria-pressed`로 표현합니다.
